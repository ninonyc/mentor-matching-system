# C++ matching core

- `include/`: declarations in header files (`.hpp`).
- `src/`: implementations (`.cpp`).

Phase 1 will introduce `matching.hpp` and `matching.cpp` for mentor-proposing
Gale–Shapley. Phase 2 will introduce `stability.hpp` and `stability.cpp` for
independent assignment and stability checks. These files are planned, not
implemented in this scaffold.

Keep this core independent of HTTP, databases, and UI code.
